# AI HR Recruitment Simulator

## Project Overview
An AI-powered recruitment platform that automates resume screening, candidate matching, interview assessment, and AI-driven hiring recommendations.

## Frontend Tech Stack
- React.js
- Vite
- JavaScript
- CSS3

## Features

### Admin Dashboard
- Dashboard Analytics
- Candidate List
- Resume Management
- Job Description Management
- Match Results
- AI Recommendations
- Interview Results
- Analytics
- Settings

### Candidate Dashboard
- Profile Management
- Resume Upload
- AI Skill Analysis
- Job Recommendations
- Applications Tracking
- Interview Status
- AI Mock Interview
- Skill Assessment
- Settings

## Installation

```bash
git clone https://github.com/XTRAGRAD-AI/AI-HR-Recruitment-Simulator.git
cd AI-HR-Recruitment-Simulator/frontend
npm install
npm run dev
```
